**Status: PROPOSED COMPLETE DEPENDENCY/PROJECTION ALGORITHM; NOT ARCHITECT-ACCEPTED, EXECUTED, SIGNED OR NATIVE-QUALIFIED.** This document joins the existing owners: [D3 CR14 semantic content](d3-core-registry-value-contract.md), [D2 identities](d2-identity-and-type-resolution.md), [Canonical Graph C9/C10/C12](canonical-project-graph-and-components.md), [D6 canonical byte writer](d6-canonical-persistence.md) and [D6 offline package lock](d6-offline-dependency-resolution.md). If a field conflicts with one of those owners, fix the owner before accepting this integrator.

## DG0. What this pipeline actually proves — and what it cannot

A successful digest calculation proves **only** that given *independently validated* meaning-bearing bytes map deterministically to a hash. It **does not** prove any definition's authority, producer signature, source ownership, approved type semantics, ABI compatibility, runtime safety or permission. Production digest output is **blocked** while any current 15-type core definition is `UNVERIFIED`, any public Rule/TypeRef is unresolved, any lock/hash assertion mismatches or any required architectural review is absent. A separately named **candidate arithmetic mode** may calculate reference vectors for design review, but MUST label them `UNTRUSTED_ARITHMETIC`, MUST NOT populate a canonical signed Graph, must not produce `GraphLinkedIR`, and must not impersonate a release `contractDigest`.

## DG1. Canonical byte and domain preconditions

1. Parse source/authored JSON as strict UTF-8 under **D6 P1**: no BOM, unpaired surrogates, decoded duplicate keys, trailing material, unsupported number tokens, NaN/Infinity or resource budget bypass. Convert only after the exact current source and package lock are captured. Source identifier NFC is distinct from value-string non-normalization.
2. Build **closed typed projections**, never hash an authored JSON object with keys opportunistically removed. Reject unknown schema fields or altered public semantics until the owning schema and this projection are both reviewed. The only numeric JSON tokens admitted to D6 semantic projections are valid integers within IEEE-safe magnitude; U64 must use its explicitly typed string carrier.
3. Canonical writer: recursively sort object keys by exact decoded **UTF-8 byte** sequence; serialize actual UTF-8 scalar values without NFC changes; quote/escape as D6 P1; no spaces/BOM/trailing newline. Preserve meaning-bearing arrays, notably record fields, enum variants, generic arguments and command arguments. Sort **set-like** arrays only after unique-ID validation, with specified keys. **Do not sort** a semantic ordered list to make a test pass.
4. For each distinct approved domain `D`, compute `SHA256(ASCII(D) || 0x00 || canonicalUTF8(projection))`, lowercase 64 hexadecimal characters. Domain bytes and exact projection keys are **one inseparable specification**. If either changes meaning or bytes, the future accepted domain must change; do not silently reuse an older domain.
5. Reference hashes from historical v1/v2/G1 profiles, symbolic enum vectors and identity-only generic `@inst` examples remain **separate historical/candidate evidence**, not current production hash authorities. Do not upgrade by string substitution.

**Important type ID distinction:** for a public nominal record/enum/core, C9's `exportId` is the exact fully qualified authored type ID; for a generic instance it is the separate proposed D2 I9 *identity-only* derived `@inst` ID, **not** its semantic `contractDigest`. The generic's `packageId` in C9 is the owner of its outermost template. `exports` in a type-export-set are unique by `packageId,exportId`; same ID with another digest is **conflict**, not a second type entry. The type-set projection is **a new proposed closed owner detail**, not a second authored project field; C9 and D6 must explicitly approve it.

**Package scope is separate:** `components.package.exportedTypeSetDigest` refers to the full public type export closure of **that package's entire exported type surface** (including exact transitive dependencies required by the package contract), whereas Graph `typeExportSetDigest` covers the **transitively reachable Graph-resolved public type set** and its core fingerprint. The candidate domain framing may be shared only if the *scope is explicit inside the projection* and authority approves that choice. Until resolved, **do not reuse the Graph type-set hash as a package asserted exportedTypeSetDigest or vice versa**. This is a **P0 design blocker**.

## DG3. Exact dependency and trusted comparison algorithm (future compiler/verifier)

1. **Immutable source admission:** validate package/source JSON and source digests, lock objects, declared package IDs/versions and normalized aliases, and all required byte hashes. Validate non-authored package source list and native target qualification separately. Do not treat package lock as a source approval signature.
2. **One trusted 15-entry registry:** check exact unique TypeIDs, arity/traits/ordered variants, **34 content-bearing rule definitions**, and CR14 ID-to-definition set equality. Confirm immutable version/source, provenance and architect acceptance. **Current state fails here: every export is UNVERIFIED.** Candidate arithmetic may continue in a restricted nontrusted review-only tool, never publishing release outputs.
3. **Core type projections:** sort CR14's unordered logical trait/rule sets by decoded UTF-8 bytes, retain ordered parameters/variants, include full text definitions; compute each independently with the proposed type domain **only after Step 2**.
4. **Core fingerprint:** sort the 15 `{typeId,contractDigest}` pairs and compute exact registry projection. Compare any authored `coreRegistryFingerprint` as an assertion; never trust it to fill a dependency.
5. **Nominal public exports:** inspect all loaded package record/enum definitions, resolve exact type/owner aliases, build edges from field/payload types, reject missing, duplicate, incompatible or **cyclic by-value** dependencies; compute leaf-first. A constructor expression or enum native tag is **not** a public type projection.
6. **Derived generic instances:** resolve the exact verified template and each argument inside-out. Apply arity, depth <=8, nodes <=128, ownership/Send and portable Graph payload rules. Build **D2 identity-only** export ID separately; compute full type-contract digest from the complete *verified* TypeReferences and register in the **same C9 type set**. No digest-of-itself or cycle.
7. **Operations:** resolve every complete parameter/success/failure TypeReference from computed trusted type exports, verify effect/domain/target/sideEffectClass/retry and authenticated interface↔locked-provider match; build C12 operation projections and digests. Missing effects, capabilities or provider rejects; a `service` declaration is not an implementation.
8. **Components:** resolve all ports/types and the **exact complete** declared operation set, compute each component projection/digest; source paths/implementation hashes are excluded from logical digest but MUST remain verified in the build lock.
9. **Type export set:** collect all public types **reachable from the full Graph** through nodes/ports, operations, workflows/dataFlows, record/enum payloads and transitive generic arguments. Include every required core leaf/derived instance; reject orphan declarations improperly claimed as reachable, missing closure edges, or duplicate IDs. Compute type-set projection with exact accepted scope. Check package exported set(s) **independently** under the separate P0 scope rule.
10. **Full Graph:** construct the complete C9 projection with verified `resolvedExports` of type and component and all semantic fields. Check authored fingerprint/set and node component digest against recomputed values. Compute semanticGraphDigest with its **distinct** domain; unchanged view layout/revision/ASM formatting alone must not change its logical hash, while implementation/content lock changes still invalidate native build approval.
11. **Source link and native build:** reconcile reviewed exact AUI source spans/type symbols, snapshots and immutable Graph semantic result; produce verified `GraphLinkedIR` **only with signed review/lock proof**. Build native TargetMIR/ABI objects and runtime imports separately. A digest match grants no OS/hardware permission; native module signature/live capability is another gate.
12. **Durable release:** write complete hashes/source maps/evidence into D6 immutable staged output with atomic verify/publish and separate signed artifact admission. Never hash a containing snapshot digest or signature into its own logical ancestor.

**No successful results from later stages may survive a failed earlier gate.** Internally cached review projections may be inspected as `UNTRUSTED_ARITHMETIC`, but there is no production Graph mutation, trusted IR promotion, publisher approval or authorized binary output.

## DG4. Deterministic conflict, recursion and error policy

| Condition | Required failure |
| --- | --- |
| Any current 15 core type UNVERIFIED, rule meaning not accepted or absent 34-rule closure | `CORE_REGISTRY_UNRESOLVED`; no trusted core digest/fingerprint |
| Unknown/deleted referenced TypeID, stale nested generic instance, duplicate `packageId+exportId` or inconsistent claimed digest | `GRAPH_EXPORT_UNRESOLVED` or `CORE_CONTRACT_DIGEST_MISMATCH`; fail before dependent operation |
| By-value dependency cycle (record→enum→record, generic/list recursion), graph dependency cycle affecting type evaluation | `TYPE_CONTRACT_DEPENDENCY_CYCLE`, include exact ordered cycle identities; no hash |
| Same-ID changed rule text, enum variant order/payload, generic argument order or operation effects | Recompute the candidate projection and all downstream dependents; if old author assertion remains, reject stale digest |
| Invalid decoded object-key duplicate, canonical number, UTF-8, schema, resource bound or unordered set duplicate | `CANONICAL_INVALID`/schema-specific failure, no silent lossy normalization |
| Unverified generic template trait/arity, owner or derived `@inst` namespace | `TYPE_CONTRACT_UNVERIFIED` or `TYPE_CONTRACT_ARITY`; do not accept 64-hex placeholders |
| Mismatch in package exportedTypeSetDigest versus Graph typeExportSetDigest scope | `TYPE_EXPORT_SCOPE_UNRESOLVED` until separately approved distinct scope mappings |
| Invalid source approval/signature, unsupported native target/ABI, changed lock/source bytes, missing live capability | Dedicated trust/target failure; **digest match never overrides it** |

For deterministic reporting, check lexical/schema/lock/namespace, then core definitions, public dependency SCCs, template arity/traits, type projections, operation projections, component projections, type-set, full graph and source/runtime trust in that dependency order. Within a stage report errors by normalized export identity and original source byte span, bounded count. Do not invent a source span before bytes have been successfully captured. Error names and precedence remain **candidates** until an approved native diagnostic format exists.
