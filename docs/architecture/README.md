# AELYXORA Studio — Architecture

**Status:** evolving design · **Implementation:** not started.

AELYXORA Studio is an open-source AI-native RAD environment for visual, architecture-driven, source-controlled application development. It combines Delphi/WinDev-like design productivity with explicit component contracts, AI-assisted modifications and deterministic build/test verification.

## Architectural principles

1. **Typed Application Model:** declarative project structure is canonical. Handwritten source remains authoritative for its own implementation.
2. **Three coordinated authoring modes:** Visual Designer, AI Architect and Code Editor; arbitrary code is never assumed to be losslessly reverse-engineerable into a model.
3. **Headless core:** project loading, migrations, validation, edits and generators do not depend on the IDE UI or on an AI provider.
4. **Controlled AI:** AI proposes structured operations or reviewable patches; validation, permissions, builds and tests are separate deterministic gates.
5. **Backend neutrality:** the model is independent of Qt. C++ / Qt 6.12 / QML is the initial IDE stack and Qt/QML the first generated GUI backend.
6. **Code ownership:** generated and handwritten code have explicit boundaries; regeneration never overwrites unknown human edits.
7. **Local-first and open:** human-readable projects, version control, reproducible builds, no compulsory cloud service.
8. **Honest status:** roadmap targets are not represented as implemented features.

## System overview

```text
                  IDE Shell (C++ / Qt 6.12 / QML)
       Architecture | Designer | Data | Logic | Code | Debug
                                |
                   Application Services
        Transactions | Undo/Redo | Workspace | Diagnostics
                                |
                    Headless Model Core
          Schema | Typed IR | Validation | Dependency Graph
                                |
           Generator and Integration Adapters
      Qt/QML | CMake | Compiler | LSP | Debugger | AI | Storage
                                |
                Standalone generated projects
```

Dependencies point inward toward the core. Projects generated by AELYXORA must not require the IDE to execute.

## Deliberate limits

The first usable slice is a generated desktop CRUD app with a real SQLite database, typed form bindings, manual source extension, tests and a distributable package. A custom compiler, universal native GUI generation, mobile/server release parity and public component marketplace are **not** initial deliverables.

Version identifiers belong to persisted schemas, component APIs, migration formats, and public compatibility contracts. The architecture itself is a living document, not a named versioned release.
